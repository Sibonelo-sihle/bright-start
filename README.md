# Bright Start Edu Recruitment

Bright Start Edu Recruitment is an education recruitment platform for schools and educators across Zimbabwe and the wider region. This repository contains the public website only.

## Repository structure

- `frontend/` — React/Vite public website.
- `backend/` — reserved for future server-side integrations and privileged operations.
- `database/` — reserved for future database schema, migrations, and seed tooling.
- `docs/` — architecture, setup, and deployment documentation.

The public website reads published vacancies and submits enquiries, staffing requests, and educator applications through Supabase. Administrative tooling is maintained in a separate repository.

## Run the frontend

```bash
cd frontend
npm install
npm run dev
```

## Lint

```bash
cd frontend
npm run lint
```

## Production build

```bash
cd frontend
npm run build
```
